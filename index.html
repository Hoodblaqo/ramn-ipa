Install on iPhone

In Safari, tap Share → Add to Home Screen. The icon opens RAMNTIFY in an app-like window.

Offline support

The app shell can reopen offline after its first successful load. Spotify search and playback still require internet.

About this edition

This is a web companion, not the original native IPA. Native-only tweaks, system integrations and unrestricted background playback are not available in Safari.
